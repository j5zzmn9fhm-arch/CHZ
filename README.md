CHZ DISCOVERY

Aplicativo para descoberta e identificação de Smart TVs.

## Objetivo
Identificar Smart TVs conectadas à mesma rede Wi-Fi.

## Primeira versão
- Descoberta de dispositivos Roku
- Identificação de marca e modelo
- Exibição do endereço IP
- Interface moderna em preto e cinza

## Tecnologias
Swift e SwiftUI.
